# curatomatic

Semi-automated curation of GTDB reference trees for new releases.

_This tool was developed for internal use, it is not supported for public use._

## Installation

In a virtual environment, install the following Python libraries:

```shell
python -m pip install dendropy tqdm typer
```

Then, clone the repository into a directory.

```shell
git clone https://github.com/Ecogenomics/curatomatic.git
```

## Running

### Help

Within the cloned repository, run the following command to view the CLI help:

```shell
python -m curatomatic --help
```

### Arguments

The following arguments are required:

```shell
python -m curatomatic [OPTIONS] TREE RED_DICT OUT_DIR          
```

- `TREE` = Path to the RED decorated and scaled tree (generated by Phylorank).
    - e.g. `gtdb_r232_bac120.decorated.red_decorated.tree` 
- `RED_DICT` = Path to the RED dictionary (i.e. the JSON that contains thresholds).
    - e.g. `gtdb_r232_bac120.decorated.dict`
    - The Rust version reads a TSV instead, see [Median RED file](#median-red-file-median_red).
- `OUT_DIR` = Output directory to write to.

Note: The `TREE` is the pre-curation tree and **must contain zombies** (e.g. D-G123456789).

The following arguments are optional:

- `--log [debug|info|warning|error|critical]` = Output logging messages equal, or above this level.
- `--min-bs FLOAT` = Minimum bootstrap value to consider for decoration (default = 95.0)


### Example

The example can be run using the following command:

```shell
python -m curatomatic example/gtdb_r226_ar53.decorated.scaled.red.tree example/gtdb_r226_ar53.decorated.dict /tmp/output
```

## Rust

A Rust re-implementation of curatomatic is also available. It takes the same arguments and writes the same output as the Python version.

### Building

```shell
cargo build --release
```

The binary is written to `./target/release/curatomatic`.

### Running

```shell
./target/release/curatomatic [OPTIONS] <TREE> <MEDIAN_RED> <OUT_DIR>
```

`TREE` and `OUT_DIR` are the same as above, and `OUT_DIR` must not already exist. `MEDIAN_RED` replaces the JSON
`RED_DICT`.

#### Median RED file (`MEDIAN_RED`)

A tab separated file with a header and one row per rank, giving the median RED of that rank, e.g.
`median_red_rank_distribution.tsv` (see `example/gtdb_r226_ar53.median_red_rank_distribution.tsv`):

```
rank	median
Phylum	0.23103292252099542
...
Genus	0.9068450718741943
```

- The `rank` and `median` columns are found by name. Any other column (e.g. `mean`, `p95`) is ignored.
- A rank is its full name, in any case (`Phylum`, `phylum`).
- The domain is always `0.0` and the species always `1.0`. They need no row; a row for either must have that value.
- A missing column, a median that is not a number, an unknown rank, or a rank given twice is an error.

#### Novel name file (`--novel-name-file`)

A tab separated file with a header, giving the name (e.g. the NCBI WGS prefix) used for each genome when a novel
taxon is created. The GTDB metadata file can be used as is, e.g. `gtdb_r237_bac120_metadata.tsv` with
`--novel-name-column ncbi_wgs_formatted` (see `example/meta.tsv`):

```
accession	ncbi_wgs_formatted
GB_GCA_123456789.1	FOO
```

- Only the `accession` column and the column named by `--novel-name-column` are read, both found by header name. Any
  other column is ignored.
- A value of `none`, `n/a`, `null` or empty (after trimming, in any case) means the genome has no name.
- A missing `accession` or name column, or a row too short to hold either, is an error.
- Genomes without a name are given novel taxa named after their genome ID.

The following options are available:

- `--log [debug|info|warning|error|critical]` = Output logging messages equal, or above this level (default = info).
- `--min-bs FLOAT` = Minimum bootstrap value to consider for decoration (default = 95).
- `--novel-name-file PATH` = File giving the name used for novel taxa of each genome (see [Novel name file](#novel-name-file---novel-name-file)). Requires `--novel-name-column`.
- `--novel-name-column NAME` = The column of `--novel-name-file` that holds the names, e.g. `ncbi_wgs_formatted`. Requires `--novel-name-file`.
- `-h, --help` = Print the help.
- `-V, --version` = Print the version.

Example:

```shell
./target/release/curatomatic --min-bs 95.0 \
    --novel-name-file example/meta.tsv --novel-name-column ncbi_wgs_formatted \
    example/gtdb_r226_ar53.decorated.scaled.red.tree example/gtdb_r226_ar53.median_red_rank_distribution.tsv /tmp/output
```

### Output

The following files are written to `OUT_DIR`:

- `<tree stem>.curatomatic.tree` = The curated tree, where `<tree stem>` is the file name of `TREE` without its last extension (e.g. `gtdb_r226_ar53.decorated.scaled.red.curatomatic.tree`).
- `curatomatic.log` = The log of the run.

### Testing

```shell
cargo nextest run
```
