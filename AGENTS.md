# AGENTS.md


## About
Curatomatic was originally written as a Python library to perform pre-curation of a domain-specific prokaryotic phylogenetic tree.
The logic of the program follows several cases that have been identified as manual steps that curators of the tree perform. The aim is to remove as much manual work as possible.

The project has been re-written in Rust to ensure type safety and improve performance for large trees.
The tree uses information based on Relative Evolutionary Divergence (RED) and a pre-decoration of the tree using a different software package.

## Test data
Reference data under `./test_data` was generated by the original Python library. The Rust implementation has since
diverged from it on purpose, so these outputs are no longer expected to match exactly. Use them as realistic inputs and
as a baseline for reviewing what a change does. You can find the command used to run curatomatic in the first line of
each log file, e.g.: `test_data/r226_bac120/curatomatic_bs95.0/curatomatic.log`.

Each domain (ar53 - archaea, bac120 - bacteria) has been run three times using different minimum bootstrap values. All
curatomatic output is under each test directory with the name `curatomatic_bsVALUE`. Input data is in the root of each
directory - both `r226_ar53` and `r226_bac120`.

Curatomatic must never change the structure of the tree or its bootstrap values: the only changes to the final tree
are the labels at each node (which form the taxonomy).

## Rules
- Tests live in a separate file, never inline: declare `#[cfg(test)] mod tests;` in `foo.rs` and put the tests in `foo/tests.rs` (see `src/taxonomy.rs`).
- When possible, use newtypes.

## Rules (for development only)
- During this active stage of development, do not run lints (including clippy).
